# HOURGLASS releases

Installable Android builds of [HOURGLASS](https://syncratic.app/projects/hourglass), a focus
timer where your time is the only currency.

Each version is a [release](https://github.com/Syncrose1/HOURGLASS-releases/releases) with its
APK attached. Every build is signed with the same key, so a new one installs over the last
without losing your data.

This repository only holds the builds.
